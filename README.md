# Grøndalsvænge 2.0

Statisk website for Andelsboligforeningen Grøndalsvænge.

**Status:** Discovery og planlægning. Første POC anvender normaliserede mockdata; Google Workspace-integrationen kommer senere.

Arkitekturen adskiller kildedata, versionsbundet publicering og Astro-frontend. Kun godkendt offentligt indhold må indgå i en build.

Se arbejdsbranchen `docs/gvnewweb-discovery` for designoplæg, implementeringsplan og Codex-instruktioner.
